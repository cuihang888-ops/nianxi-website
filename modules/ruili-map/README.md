# 瑞丽地图模组（地区包：瑞丽）

安和里 / 德宏世界的第一张地区包。内容 = 瑞丽的**地理底图数据**（真实比例）+ 纯地图 + 可玩组装演示 + 契约层与植被/天气数据模组。
本包是**地图模组**，不含人物、房屋、动物、物品等内容包（见「外部依赖」）。

风格：童话故事书式渲染（柔和粉彩、圆润形状、碎花草甸、奶油色道路、天蓝河流）——纯地图与演示的概览/跟随视角均按此风格绘制。

---

## 1. 分层（按「换地区时变不变」分类）

| 层 | 内容 | 换地区时 |
|---|---|---|
| 契约层 | `contract/content-registry.js`（NXContent：内容包注册、存档根只有一个 `mods` 对象 + 各包命名空间、迁移只增不删） | 永不变 |
| 数据层 | `data/ruili-map-data.json` / `.cjs`（瑞丽地区包）、`data/content-flora.js`（NXFlora）、`data/content-weather-festival.js`（NXWeather） | 只换数据 |
| 表现层 | 渲染器 / 精灵缓存 / 光影 / 音频总线（本包的演示 `demo/` 内含一份参考实现） | 永不变 |
| 系统层 | 参数化系统（种植、天气驱动等，参数来自数据层） | 只调参数 |

## 2. 加载契约（重要）

- CommonJS 宿主（微信小游戏 vendor 风格）：**先**执行
  `globalThis.NXContent = require('./content-registry.js')`
  **再**加载 `content-flora.js` / `content-weather-festival.js`——后两者读全局 `NXContent` 注册内容包，缺失会直接抛错。
- 浏览器宿主：先 `<script>` 引入 registry（UMD 会挂 `window.NXContent`），再引入 flora / weather。
- 演示 `demo/ruili-playable-assembly.html` 已按此顺序内嵌 registry + flora（逐字内嵌，便于单文件试玩）；weather 本轮**未**接入演示（见第 7 节 staging）。

## 4. 地图比例 = 世界比例（一把尺）

地图上画多大，世界里就占多大，没有单独的「地图缩放」。已植入元素按真实占地绘制：

- 羊圈 / 预留宅地 30×32 单位 ≈ **190×200 米**
- 山寺台地 44×34 单位 ≈ 275×210 米
- 瑞丽江宽 55 单位 ≈ 340 米；道路宽约 7 单位（只变长、不变宽）
- 纯地图带公里比例尺（1 公里 = 160 单位）与占地注记

## 6. 植被：NXFlora 驱动散布（数据层）

演示的植被散布已改由 `NXFlora` 物种按生境（biome）驱动，物种渲染走 `NXFlora.createFloraCache` 精灵缓存（`drawFlora` 预合成）。地形/位置 → 生境映射：坝子平原→坝区，丘陵/山地→山地，河湖岸→水边，道路两侧→路边，地点周边→寨内，姐勒金塔台地→寺院。第一遍每生境只放 2–3 种（不倾倒全部 20 种），实测放置（种子 20261118，确定性）：

| 生境 | 物种（放置数） |
|---|---|
| 坝区 | 芒果 mango 116、甘蔗 sugarcane 129、木棉 kapok（与路边合计 255） |
| 山地 | 柚木 teak 269、橡胶树 rubber 262、野蕨 fern（与水边合计 357） |
| 水边 | 凤尾竹 bamboo（与路边合计 251）、睡莲 lotus 44（湖面近岸）、野蕨 fern |
| 路边 | 三角梅 bougain 109、凤尾竹、木棉 |
| 寨内 | 大青树 banyan 20、芭蕉 banana 26、三角梅 |
| 寺院 | 菩提树 bodhi 2、贝叶棕 talipot 2（台地外四角） |

NXFlora 植被总数约 1,957 处；另有通用背景散布（圆冠树约 2,500、岩石 850、草丛约 1,100、芦苇 821、概览碎花约 900），全部种子化、按视野裁剪。林地（莫里雨林等）本遍用背景圆冠树 + 纯地图上的团簇树冠表现，未单独配物种。
