# 茶水间 · 给 Codex 的上线说明

## 这是什么
给现有「协作中心」新增的一个板块，名字就叫**茶水间**（不带公司名前缀）。
员工内部论坛，定位刻意做简单：**不涉及个人收入、不涉及个人/部门业绩数据**，
不要往这个模块里加提成、工资、排行榜、开单/实收统计。

## 板块结构（7 个，已全部实现）
1. **话术库** — 搜索 + 分类（砍价 / 证书售后 / 色名意境 / 活动 / 英文 / 越南语）+ 一键复制 + 收藏排序 + 员工贡献
2. **优秀案例分享** — 标题 + 情况/做法/结果 + 收藏
3. **匿名留言板** — 完全匿名，系统随机匿名昵称，可点“加油”
4. **励志墙** — 发励志话、点“加油”，被加油最多的一句自动置顶到茶水间首页（每日一句）
5. **求助台** — 发帖提问、回答、发帖人标“已解决”
6. **匿名建议箱** — 匿名提交生成编号（如 JY-1234），提交人凭记录查进度（已收到 → 处理中 → 已回复）；已回复的公开在同页
7. **生活集市** — 拼车 / 夜宵拼单 / 二手闲置 / 租房，留内部称呼联系，不留私人电话

首页 = 每日励志句 + 话术搜索 + 公告一行 + 7 个入口 + 案例/留言/互助最新各几条。

## 文件
- `tearoom/index.html` — 完整单文件应用（HTML+CSS+JS，无外部依赖，手机端优先，视觉风格对齐协作中心截图：浅绿灰底 #edf2ec、深绿 #17503c、白卡圆角）
- `integration/home-entry-snippet.html` — 协作中心首页入口卡片代码片段

## 上线步骤（建议）
1. 把 `tearoom/` 目录放到协作中心站点根目录下（或任意子路径）。
2. 在协作中心首页「看板」卡片之后插入 `home-entry-snippet.html` 的卡片，href 按实际路径调整。
3. 茶水间页面左上角“‹ 协作中心”的返回链接默认指向 `../index.html`，按实际层级改。
4. 不需要登录态改造：沿用协作中心现有的访问方式即可（本模块不单独做账号）。

## 数据与后端预留
- 当前版本是**纯前端演示版**：数据存在浏览器 `localStorage`（key `tearoom-v1`），
  内置种子内容（话术 6 条、案例 2 条、留言 3 条、励志 3 条、求助 2 条、集市 3 条、示例建议 1 条）。
  换设备/清缓存会丢数据，**正式多人共用前请接后端**。
- 接后端时页面字段不用改，按下面接口替换 load/save 即可：
  - `GET /api/tearoom/scripts?cat=&kw=` / `POST /api/tearoom/scripts`
  - `GET/POST /api/tearoom/cases`
  - `GET/POST /api/tearoom/board`（服务端不要返回发帖人身份字段，匿名从数据层保证）
  - `GET/POST /api/tearoom/wall`，`POST /api/tearoom/cheer {id}`（励志+留言共用加油）
  - `GET/POST /api/tearoom/help`，`POST /api/tearoom/help/:id/answers`，`POST /api/tearoom/help/:id/solve`
  - `POST /api/tearoom/suggest`（返回编号），`GET /api/tearoom/suggest/mine`（按登录态），管理端改状态/回复走现有管理员登录
  - `GET/POST /api/tearoom/market`
- 收藏/加油的防重复：前端用本地标记，后端版请按账号去重。

## 内容运营（上线第一周，麻烦转达给用户）
- 版主 1 人即可：每天把励志墙被加油最多的一句确认置顶（系统自动排，人工只审核违规）。
- 红线只有两条：不发客户隐私（姓名/电话/地址）、不点名骂同事。其他内容不要预审，先发后审。
- 种子话术里的活动话术（12月累计消费大奖）是占位示例，上线前请企划确认口径再保留。

## 验收清单
- [ ] 协作中心首页能看到「茶水间」卡片，点进能打开，返回能回到协作中心
- [ ] 手机端（微信内置浏览器）打开排版正常，底部导航不遮内容
- [ ] 话术库搜索“砍价/证书/晴底”能出结果，复制按钮可用
- [ ] 匿名留言发布后只显示随机昵称，不出现任何真实身份
- [ ] 励志墙加油后，首页每日一句随票数变化
- [ ] 建议箱提交后能看到编号和“已收到”状态
