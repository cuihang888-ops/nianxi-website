# 安和里的产品方向

更新日期：2026-11-13。依据用户对产品初衷的说明。

安和里希望给承受工作、收入和生活压力的年轻人一处可以暂时歇脚的地方。祈愿让心绪安定，简单的养成和动物陪伴带来被回应、有所照顾、有一小片归处的感受。

## 设计取舍

- 庭院、静坐、心灯、喝茶和山谷散步都可以独立成立；不强迫每次进入都完成任务。
- 动物要有自己的名字、自然动作和温柔的照料回应。亲近感比单位时间产出更重要。
- 离开后不惩罚用户，不让动物因缺席死亡，不设置连续登录断签损失，不用排名制造比较压力。
- 土地、种植、收获和轻量山林探索提供小目标。避免把每项活动都变成高频催促和倒计时。
- 愿望和仪式表达陪伴与祝福，不承诺现实中的财运、健康或命运结果。
- 在线人数和互动必须真实。当前个人牧场仍是本机存档，跨设备、云端和账号同步未完成。
