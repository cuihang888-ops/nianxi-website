# 安和里的产品方向

更新日期：2026-11-15。依据用户对产品初衷与多人共同生活方向的说明。

安和里希望给承受工作、收入和生活压力的年轻人一处可以暂时歇脚的地方。祈愿让心绪安定，简单的养成和动物陪伴带来被回应、有所照顾、有一小片归处的感受。

## 设计取舍

- 庭院、静坐、心灯、喝茶和山谷散步都可以独立成立；不强迫每次进入都完成任务。
- 动物要有自己的名字、自然动作和温柔的照料回应。亲近感比单位时间产出更重要。
- 离开后不惩罚用户，不让动物因缺席死亡，不设置连续登录断签损失，不用排名制造比较压力。
- 土地、种植、收获和轻量山林探索提供小目标。避免把每项活动都变成高频催促和倒计时。
- 愿望和仪式表达陪伴与祝福，不承诺现实中的财运、健康或命运结果。
- 在线人数和互动必须真实。当前个人牧场仍是本机存档，跨设备、云端和账号同步未完成。

## 当前协作范围

新方向：德宏五市县作为共同生活世界的灵感，瑞丽总佛寺作为共同祈愿与相聚的中心。每位真实玩家拥有自己的角色，在持久共享村落中选择地块安家，能看见邻居的房屋、农田与动物，种养、出售产物获得游戏内安币，再一起到寺院祈福、挂红结。村落持续扩展，离线不失去地块；在线频道与土地归属分开。

交通仅步行与骑马；采用原野想象，不把场景当作真实古代德宏复原。安和里独立推进微信小游戏，已有本机预览与 iPhone 进入庭院的用户确认；真实账号、云存档、共享地权和新世界多人尚未接通。商城保留入口。当前交接见 `MUSE_SHARED_WORLD_HANDOFF_20261115.md`，整体框架见 `DEHONG_WORLD_FRAMEWORK.md`。

Codex 负责平台、账号、世界服务、地权、经济与验证闭环；Muse 负责地图、角色、动物、建筑、画面、交互细节和客户端完整流程。首发免费不充值，现有数值与手感保持；“赚钱”仅指游玩获得安币，不兑换现金。未来商业化另行立项。

只继续安和里。年禧商城其他功能保持现状，原自动罗盘和万年历文件保持字节一致。给 Muse 的旧 ZIP 以提交 `044c034` 为基线；本地后续修改需要按文件差异合并，不能直接用旧包覆盖。
