本次把累计包中的游戏增量接到已有微信平台宿主，保留商城、支付、订单、原日历和原网页运行入口。没有整体应用基于旧提交 `a28d1b7` 的 patches，也没有运行归档中的安装脚本。

- 七个场景：瑞丽总佛寺庭院、溪山牧场、芒市坝、瑞丽坝、盈江坝、陇川坝、梁河。
- 五坝步行、骑马、传送、基址安家和 600 安币自选地块；建草棚、开田、种收、养鸡兔羊、升级竹楼。
- 马匹每日喂食与刷毛各一次，亲密度只增不减；跟随、安全落点唤马、跨坝后恢复。
- 30 项图鉴及三种节日布景；图鉴和大厅在小屏分页，节日按配置日期每年领取一次。
- 北京时间昼夜与按日期确定的天气；五坝雨丝与萤火使用可复用几何，不改经济或任务。
- 家园出产和萝卜装入背篓，在集市按原价出售；出售失败保留货物，重试不重复入账。
- 已有产出显示为田边收获篮；空闲时屋前休憩、移动起身，不增加货币或加速生产。
- 新档免费点亮当地水晶；未点亮坝区可以免费古道行旅，已点亮目的地才允许付费传送。旧档缺失 `lit` 时按已有家园和马匹迁移点亮记录。
- 节日首次参加每年领取一次奖励，之后可以免费泼水、放灯或随队纵歌；重复互动不写入余额，不增加奖励。走动、切景和暂停停止纵歌，特效使用有上限的资源池。
- 30 项图鉴手记，已收录条目才能打开。正文随屏幕宽高分页，返回保留原列表页；未核实的具体地理历史表述改为游戏内场景描述。
- 第 26 轮调整芒市集市河面和水晶落点，连续化五坝河道水面，移动梁河衙门并同步发现圈，温泉蒸汽半透明，纵歌场补暖灯。
- 集成中修复节日重复互动遮住卖货入口的问题：背篓有货时优先售卖，售完仍可参加节日；窄屏动作按钮保留完整金额，避免把数字拆到两行。

## 平台与存档

`wechat/game-entry.js` 为浏览器与微信共用工厂，宿主只创建一张屏幕画布并管理输入和帧循环。Canvas UI 使用受宿主管理的离屏画布。调整尺寸时重建 CanvasTexture，以避免部分 WebGL 实现的纹理拉伸和重复。

游戏使用 `anheli-minigame-v2:save` 版本信封。原 `anheli-minigame-v1` 字符串和微信对象存档只在校验通过后复制迁移，原键保留。历史家园、马匹、图鉴和背篓字段按需补齐。损坏存档不覆盖；写入失败回滚同一状态对象，不扣钱、不显示成功动画；不同窗口的版本冲突不覆盖已有进度。

`preview-economy.cjs` 保存数值，`preview-discovery.cjs` 保存目录、地标与集市，`preview-sky.cjs` 保存天空配置。场景不能直接修改货币或归属。自动发现、节日与经营动作均通过存档事务提交。暂停或切景保存马的位置，包括尚未骑乘的跟随马。

## 试玩与验收

启动浏览器试玩：`npm run trial:minigame`，地址 `http://127.0.0.1:5180/`。浏览器入口调用同一游戏工厂；默认使用现代 Three.js，`?renderer=wechat` 使用实际打包的 r108 适配器。`?test=1` 只开放本机验收接口，普通试玩没有测试状态接口。

自动验收入口：`npm test`、`npm run test:ui`、`npm run verify:calendar`、`npm run build:wechat`，以及 `scripts/verify-minigame-trial.mjs`。验收产物留在 D 盘项目的 `reports/`，不提交浏览器资料或截图到 Git。

2026-11-14 最终结果：

- `npm test` 240/240 通过；原网页 UI 回归 16/16 在本轮较早阶段通过，此后原网页源码未改。
- `verify:calendar` 原始源码 15 文件和网页构建 15 文件均保持原始校验值。
- `build:wechat` 通过，4 个文件、23 个模块、1,209,380 字节；构建仅生成本机工程，没有上传或发布。
- 两种浏览器渲染路径各通过 19 组端到端流程，各保存 90 张截图，均无 JavaScript 或控制台错误。桌面、390 像素竖屏、320 像素窄屏和 667 像素横屏均检查画布像素和控件边界；UI 合成对齐检测为 1.0。
- 实际操作覆盖签到、静心暂停、动物移动、种收与卖货、旧档恢复、四坝首访免费和付费返程、自选安家、每日养马到亲密度 80、跨坝唤马、三类节日重复互动、图鉴手记全文以及七景昼夜雨。纵歌真实等待完整一圈，并验证移动、暂停、切景停止。
- 场景回归另验证从出生点正常步行抵达芒市卖货与新水晶交互范围，不依赖测试瞬移；温泉透明度、夜灯和梁河碰撞位置也有检查。

现代渲染器报告：`reports/minigame-trial-round26-modern/result.json`；r108 报告：`reports/minigame-trial-round26-wechat/result.json`。最终候选 `game.js` 的 SHA256 为 `341B285AAB923961DB0C67BCE9F87FCA0930A756561252D0B7C5D1BFB8D0044B`，晋升试玩入口时复制已验收文件，不重新编译不同版本。

## 尚未完成

- 实际微信小游戏模拟器与手机的游戏版本验收尚未完成。历史诊断画布成功、浏览器运行 r108 和构建成功均不等于微信真机通过。
- 微信真实登录、云存档、共享土地、玩家交易、充值及正式发布未接通。
- 服务器身份、全服经济埋点和统一账本尚未接入本次小游戏原型；不能把本机余额或原网页日志当作全服经济数据。
- 顶部切换场景与免费回家保留为试玩便利；收费水晶不是完整交通经济。
- 古道行旅目前直接切换地图，没有连续跨坝道路、走路耗时或摆渡动画。
- 碰撞为圆形近似，不能保证所有可见河道和建筑网格均被覆盖。自选安家尚未避让道路折线。
- 站在地块中心搭建时镜头可能被屋顶遮挡；r108 与现代渲染器的色彩仍有差别。
- 节日是试玩公历窗口，正式运营须确认实际年度日期。芒市图鉴寺院已改名，避免误称为瑞丽总佛寺。
- 牧场观赏场景的点击收获仍直接给安币，未接家园背篓；当前余额只用于免费本机原型。
