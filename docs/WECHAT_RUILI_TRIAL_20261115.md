# 瑞丽本机试玩入口

日期：2026-11-15。用户选择微信开发者工具试玩，暂不接真实充值。

## 进入游戏

1. 打开微信开发者工具中的 `anheli-wechat`，工程目录为 `D:/CodexStorage/projects/nianxi-website/dist/wechat`。不要导入源码 `wechat` 目录。
2. 如显示登录码，用绑定小游戏的管理员或开发者微信扫码，在手机确认。工具访问授权由用户本人确认。
3. 点击“编译”，在模拟器看到庭院后，右上角向后切景箭头点三次，到瑞丽坝。
4. 用左下摇杆移动，点击小地图展开查看方向。样板 A/B 地块在出生点西南侧；地图只读，不能点地图传送。

## 第一处家园

- 新档一次性初始 1000 安币，旧档资产和余额保持原样。
- 样板 A/B 400 安币；走到地块附近按出现的安家按钮认领。C–H 为预留位置。
- 草棚与开田免费，种养产出进入背篓，到集市卖出获得安币。竹楼升级需要 500 安币。
- 另有 600 安币自选地；新位置会校验整座家园，不能覆盖道路、地块、公共区、河流与山体。
- 已在其他坝区建家时仍是一人一家，使用“回家”回到原家园，不清档替用户重来。
- 旧家园会按存档原坐标恢复，不因新增禁建区静默删除或搬迁。历史重叠位置未来需要有明确方案的迁移。

现在可玩的是个人本机家园、种养、集市卖货、步行骑马、瑞丽小地图和姐勒金塔山脚祈福。姐勒金塔与瑞丽总佛寺是两个地点；本轮没有把金塔当作总佛寺，也没有完成沿主干线连续走到总佛寺的地图。

“第一家大户人家”的豪宅、真实多人注册和地权、邻居同屏、云端存档尚未接入本机试玩。没有真实充值或人民币兑换，也没有正式发布。
