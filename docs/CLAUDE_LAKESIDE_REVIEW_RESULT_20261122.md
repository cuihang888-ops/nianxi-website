## 三个最影响体验的问题

### 1. 环湖点按步行在南岸一带断裂：点向南岸，人物原地不动且无任何解释

- 复现：新档出生后点按走到东南岸边（约 -7.7,-9.9，此时界面已显示「湖边」上下文、抛竿按钮出现），再点向南岸方向（-10.5,-11.5）、（-12,-13）、（-13.5,-14），连续三次点按，人物坐标纹丝不动，90 秒无位移；同样的冻结在西南侧复现两次：从西岸钓点（-24.7,-9.9）点向（-21,-13）不动。
- 期望：环湖路视觉上是一条完整的环路，玩家点向南岸应能沿路走过去——南岸正是三块湖景宅地所在，评审说明也要求步行到南岸钓鱼。
- 实际：只有按钮路线（宅基地面板「去看地」、路线按钮，内部走 BFS 寻路）能到达南岸；点按直行走在东南、西南两个弯口都被挡住，且没有任何提示解释为什么不走（现场提示反而是「走到湖岸，抛竿按钮就会出现」，与玩家「想继续往南走」的意图无关）。
- 影响：不买宅地的新玩家在南岸没有公共落点可点达，环湖散步在视觉上成立、在操作上断裂，容易直接判定「游戏卡住了」。

### 2. 「去集市办理建房」走完长路到达后，房型选择没有自动出现，要再点一次「建房」

- 复现：新档点「建房」→「去集市办理建房」，自动步行到达集市、集市面板打开后，直接找房型选项——`#houses` 的房型按钮此时不可见；再点一次底部「建房」后房型列表才出现，之后选竹木草棚、报价（建造 180 安币 · 工期 9 秒）、开工、完工都正常。
- 期望：这趟长路的目的就是办建房，到达时应直接回到建房面板并展示房型（`housing-market` 的 mode 已经带过去了）。
- 实际：到达后停在集市面板，建房流程像断了一步；这是本轮新玩家流程里最容易卡住的一步——玩家不知道还要再点一次「建房」，容易以为建房功能没做完。

### 3. 夜里湖景宅地几乎不可见：高价卖点的湖岸夜景没有灯光落点

- 复现：买下湖西望水宅地并建好竹木草棚后，用「去看地」在夜间（02:01）到达，门牌「小禾家」清晰可读，但房屋本体、宅地和环湖路几乎全黑，水面反而是最亮的区域（截图 05）。西岸夜钓（00:52）同样是岸上一片黑、只有鱼漂清楚。
- 期望：湖景宅地是 520–760 安币的高价卖点，玩家第一次去看自己的地大概率发生在任意时段；至少房屋/门牌周围应有一盏暖灯级别的落点（与 Sansa 式夜里「灯笼与窗光是唯一暖光」的标杆一致）。
- 实际：夜景氛围有了，但「家」的可见性没有跟上，玩家夜里到家看不见自己的房子。

## 逐项核对（评审说明清单）

- 钓鱼：北岸大道边、西岸环湖路边均完成抛竿→咬钩→收竿，西岸钓点相机取景人物与鱼漂同框（上一轮「树冠遮人」已修），鱼漂与涟漪清楚，鱼篓计数正常（1/12）。南岸在湖西宅地门前出现「湖边」上下文与抛竿按钮（未在此点实际收鱼）。点近岸浅水：人物走到岸边停下，无误判；点深水：不动并提示先到湖岸。
- 宅基地报价：林间 300 / 回收 225、湖西 520 / 390、湖心 760 / 570、湖东 580 / 435，面板同时列出买入价与空地回收价，与说明一致，回收均为 75%。
- 买下→退回→再买（湖西）：余额 10000 → 9480 → 9870 → 9350，每一步与报价吻合；状态文案「湖西望水宅地 · 你的宅地」正确。
- 建房：买地后点「建房」先看报价（竹木草棚 建造 180 安币 · 工期 9 秒；向导文案说明报价含宅地费与建造费），去集市开工，9 秒完工，房屋建在湖西宅地上（存档 `house.site.id = lake-west`）。
- 改名与重进：改名为「小禾」后，头顶名牌、湖西宅地门牌「小禾家」同步；重进后名字、余额 9300、房屋与宅地归属全部一致。湖心宅地在世界里有标牌（「湖心观景宅地 · 760…」）。
- 整院交接（默认存档）：集市挂牌林间木屋整院，确认文案「挂牌价 300 安币 · 含宅地、0 块田及田里作物、0 只牲畜」；切换试买角色后「买下宅院 · 300 安币」可见可点，购买后房屋归属转移、挂牌清除、余额 1000 → 700。买方门牌的视觉变化未单独截图（归属已在存档层核对，门牌机制在小禾一轮已验）。
