## 2. 画面样板做了什么

- **接地阴影**：玩家、马、家园动物、样例羊脚下统一一张柔和椭圆影（引擎层），动物啄食/跳跃时影子留在地面不跟着飘。
- **家园动物圆润化**：旧几何版不删；羊改云朵团毛（多球叠层）+头部枢轴吃草低头/抬头，鸡/兔补圆润体块与接地影，向绵绵牧场参考图的软糯感靠。
- **样板牧场**（村东 (−10, 90)，围栏 x[−19,−1]、z[81,99]，西侧 z 87..93 留门）：围栏、草棚、食槽、草料垛、南侧小溪汀步、碎花草地；与契约样板地 A 列错开，不压任何地块。
- **镜头口径**：沿用基线树冠遮挡恢复与半径钳制；内景另加相机半径/高度钳制（见 §4），殿内不穿墙。

## 5. 木鱼（声音是本体：素材与触发点就位，待 Codex 音频适配）

- 素材：`wooden-fish.wav`——22050 Hz、单声道、16-bit PCM、**0.30 s、13,274 字节**；600 Hz 基频 + 1180 Hz 泛音，衰减约 0.12 s 内落尽。按「每敲必响、连续敲击节奏跟得上」准备：短促快衰减，专为连敲不糊、不叠鸣而调。**交付说明**：该文件为二进制，本轮推送通道（push_files）只收 UTF-8 文本，未能随分支入库；已随实拍材料一并交付（与样板截图同目录 `wooden-fish.wav`），请 Codex 接入时放入 `wechat/audio/wooden-fish.wav`。
- 触发点：`world.getDecorationApi().templeFx.strikeFish()`——**每敲一次调用一次**，连敲即重触发（槌摆从头起、灯晕脉冲）；不绑死在点击上：
- **自动节律**：`templeFx.startAutoStrike(intervalMs = 900, onStrike)` 以固定间隔自动敲击，返回停止函数（另有 `stopAutoStrike()` / `isAutoStriking()`），随时可停；`onStrike` 每敲后回调，Codex 可在此排音频（Sansa 自动档与「礼拜可自动/重复」的接口口径）。
- 连敲场景（文档口径）：玩家在木鱼蒲团连点「敲木鱼」即连敲，间隔可短至连点速度；自动节律档以固定间隔（建议 800–1000 ms）持续敲击直至玩家停下或走开。
- 注意：`build:wechat` 产物只打包 JS 模块，**wav 静态资源未进 dist**——打包接入与微信音频通道（播放/静音/生命周期）归 Codex。

## 12. 逻辑修复轮（2026-11-16，用户试玩点名：房子不像房子、羊穿房）

用户 2026-11-16 15:12 试玩样板后原话：「建房子后根本就不是房子，羊也没有边界直接穿梭在房子里，正常逻辑房子是透明的空气能穿梭的吗？」本轮只修这两件事：实体碰撞与动物边界（逻辑层）、房子形态（形态层）。不改任何价格/补给/生产数值。

### 12.1 根因（如实）

- **房子从来没进过碰撞登记**。玩家移动走的 `land.resolve` 只认场景静态装饰的圆形碰撞体（水面/山体/树木）；在地块上运行时建起的房子、田块、栅栏只往场景里加模型（`buildHutVisual`/`buildBambooVisual`/`markClaimedVisual`），从未登记为碰撞体——所以房子对玩家和动物就是透明的空气。
- **家养动物没有任何碰撞与范围约束**。动物更新每 tick 直接朝「以地块中心为圆心、半径最大 4.2 的圆盘内随机点」积分位置，不做碰撞解算、不做区域钳制；而房子恰好占着圆盘中心一带（房子中心在地块局部 along −1.9，占 along [−4.85, 1.05]），羊必然逛进房子、穿墙、进田。
- **样例羊「小满」**只有最后一步的矩形钳制（牧场栅栏内侧），牧场里的棚屋柱、食槽、草垛不在它的避让名单里，玩家也能直接穿过牧场栅栏（栅栏只有模型、没有碰撞）。
- **旧房子模型本身不像房子**：草棚墙体用的是人物衣服同色的布色方块、正面大敞无门框、无窗、屋顶板与屋脊梁方向不一致，摞起来像积木；竹楼虽有高脚与地板，但没有可走的台阶/地板高度系统（玩家脚高恒为 0），门只是够不着的装饰。

### 12.2 改法（`wechat/vendor/dam-world.cjs` 引擎共用层 + `wechat/vendor/ruili-scene.cjs`）

- **碰撞登记表**：每块地在认领/建房/升级时由 `refreshPlotCollision` 按新户型占地生成一组带朝向的矩形实体（OBB，含高度区间 [y0,y1] 与门洞放行规则），与场景装饰的静态实体（`spec.solidRects`，如瑞丽牧场栅栏）合并为全坝统一的 `worldSolids`；另有地板高度区 `worldFloors`（草棚平台 0.52、竹楼楼面 2.3、台阶为斜坡段）。
- **移动解算 `resolveMover`**：玩家（半径 0.35）与坐骑（0.85）每 tick 先走原有地形解算，再逐个实体推出；步长按 ≤0.15 细分子步防穿薄墙，起点若已陷进实体先就近推出再走。门洞是墙体上的真实缺口，另有「门塞」规则：缺口只放行半径 <0.6 的移动者（玩家能进、马进不去，免得马卡在屋里）。
- **动物边界**：每块地的动物区固定在地块东侧（局部 lat [3.55, 7.95]、along [−4.85, 4.85]，与房子 |lat|≤2.95、田 |lat|≤1.57 天然错开），四周有可视栅栏（靠房一侧留 along [1.6, 3.2] 的园门）。动物的漫游目标只在区内取点；每 tick 积分后过一遍实体推出 + 区域硬钳制两道。**如实说明：动物遇阻是「挡停后换目标」，没有做沿墙平滑滑行**——停顿一下换个方向走，在慢节奏漫游里读感是「被挡住了」，不是穿模也不是原地抖动。
- **样例羊**：牧场栅栏登记为静态实体（西侧园门缺口保留），棚屋柱/食槽/草垛登记为圆形避让（羊半径按 0.85 推出）；玩家侧另加棚屋/食槽/草垛圆形碰撞（棚屋顶高 2.15，玩家的头不能钻到棚顶下）。
- **房子重做**：草棚＝奶白抹灰墙（前后左右四面墙、前墙两段+过梁留出 1.9 宽真门洞）、深木角柱与门框、门扇铰接在门框上向外开平贴墙面、侧墙窗洞（深色窗芯+木框+十字棂，窗不可穿）、茅草双坡顶（屋脊沿纵深、出檐、山墙封三角）、室内地板席、床卷、低桌、凳、篮、门前踏步石。竹楼＝高脚柱落地、架空层四面竹编裙边围合（地面层进不去，与碰撞一致）、楼面 2.3 带深色边梁、竹青墙身+深色横带、前墙门洞 1.8 宽、五级台阶带侧栏杆对正门洞、深茅草双坡顶出檐带屋脊、室内席/床/低桌。两户型的碰撞占地与新模型逐项对齐（墙厚、门宽、台阶位置同源常量）。
- **惠及范围（如实）**：碰撞与户型在 dam-world 引擎层，瑞丽/盈江/陇川/梁河四坝共用、自然惠及；芒市是独立模块（自带一份户型/动物实现），**本轮未覆盖**，待后续按同一口径移植。未给其他四坝扩美术。
