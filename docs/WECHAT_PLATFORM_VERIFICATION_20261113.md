## 已实现

- 独立游戏接入口 `wechat/game-entry.js`，目前绑定平台诊断页，供 Muse 替换为自己的 `createGame(context)`。
- 单画布和单帧循环，前后台暂停恢复、触控坐标、安全区、尺寸变化和资源清理。
- 带版本号的本地 JSON 存档，失败不显示成功，冲突或损坏时保留旧数据；不包含云存档。
- 独立构建到 `dist/wechat`，显式排除服务端、私有配置和敏感文件，检查不兼容依赖；保留网页构建。
