# 盈江全域大地图布局（2026-11-15）

收件人：Codex。配套数据模块：`wechat/vendor/yingjiang-region.cjs`（本文所有数值从该模块抄录，两边以模块为准；模块测试 `tests/yingjiang-region.test.mjs`）。
基线：`muse/shared-world-scenes` @ `8609905`（瑞丽全域图定稿之上）。用户要求原话：「顺便把其他城市的地图一起做了」，标准与瑞丽全域图一致：「能做多大做多大，大概位置的标志性的东西还是要有」，并为几千人安家留足村落基址（容量账见 §7）。
本契约只定全域布局与坐标口径，不表示规划区已建成、已可玩；现状与规划在数据里逐项用 `status: built | planned` 区分（见各表）。

## 1. 范围与两层口径

全域坐标用**坝内坐标**（与现有盈江场景 `yingjiang-scene.cjs` 的 spec 同一套：右手系、Y 向上、北 −Z、东 +X，`yaw = atan2(dx, dz)`，游戏单位不宣传为现实测绘米）。现有锚点一律不挪位，总图只向外扩：

| 层 | 范围（坝内坐标） | 面积量级 | 含义 |
| --- | --- | --- | --- |
| 现状 `playableNow` | 椭圆 cx0/cz0、rx **255**、rz **210**（包围盒 x∈[−255,255]、z∈[−210,210]） | 510 × 420 | 现有盈江场景已覆盖、已可玩的范围，数值逐字抄自 `yingjiang-scene.cjs` 的 spec `bounds`（五区里现状范围最大的一坝） |
| 总图 `masterPlan` | x∈[**−660, 660**]、z∈[**−490, 490**] | **1320 × 980** | 盈江全域总图规划范围：北抵两江入境谷口、南过铜壁关、西含凯邦亚湖与那邦方向、东去梁河 |

模块字段：`REGION_BOUNDS = { playableNow, masterPlan }`。两层之外没有第三种口径：不在 playableNow 内的，一律是规划，不得在客户端呈现为已可玩。

## 2. 坐标与投影

- 本区没有村落级契约模块（不像瑞丽有 `shared-village.cjs`），全域坐标即坝内坐标，不设第二套换算；村落开村时的村内排布在各村开村前按瑞丽村落契约同标准另交。
- 全域小地图投影（模块 `worldToMap` / `mapToWorld`，互逆，测试覆盖）：中心取总图几何中心 (0, 0)，比例 **0.5 地图单位 / 游戏单位**（总图映为 660 × 490 地图单位）；朝向定义与瑞丽版相同——map.x 东为正、map.y 向下为正（南在下、北在上，指北向上）。地图定位只读，不触发传送（交接文档红线不变）。

## 3. 水系

折线按水流方向排列；`built` 段点列逐字抄自现有场景 `riverRun` 与 spec 水面（不许挪位），`planned` 段是总图延伸。河宽为现有场景的渲染半径口径。水乡格局：两江自北来、在旧城汇成大盈江纵贯坝心。

| 水系 | 走向 | built 段 | planned 段 |
| --- | --- | --- | --- |
| 槟榔江（宽 8） | 西北来水，向东南汇入大盈江 | (−120,−210) → (−70,−150) → (−34,−105)，末点即大盈江起点 | 北延 (−190,−470) → (−156,−340) → (−120,−210) |
| 南底河（宽 8） | 东北来水，向西南在旧城一带汇入大盈江 | (110,−205) → (62,−152) → (26,−108)，末点抵旧城汇流带 | 北延 (190,−470) → (152,−330) → (110,−205) |
| 大盈江（宽 12.5） | 旧城汇流后纵贯坝心、过平原镇南下出境去芒允 | (−34,−105) → (−6,−52) → (4,10) → (−4,80) → (−16,150) → (−24,215) | 南延 (−24,215) → (−34,330) → (−40,470) |
| 户宋河（宽 5） | 西南山河，自南向北注入凯邦亚湖 | 无（现有场景未建） | (−150,472) → (−164,340) → (−168,168)，末点抵湖面南缘 |

凯邦亚湖是现有场景已建的高山水库湖面（built），在坝西南丘顶，地标表以其中心 (−168, 148) 标位（§5）。两江汇流的精确形态：现有场景里槟榔江 riverRun 的末点与大盈江 riverRun 的起点是同一点 (−34, −105)；南底河 riverRun 末点 (26, −108) 与大盈江折线之间由汇流水面圆相连（测试断言：到折线距离 < 60，在汇流带尺度内）——总图照此记录，不虚构一条不存在的河道把两段硬接上。

**坝心大道主轴说明**：盈江是全州最大的坝子，它的全域主轴就是这条沿大盈江西岸的南北大道——built 段是现有场景里玩家已经在走的那条古道（平原集市正落在它上面 (−16,−8)、大厅在其西侧 (−40,6)、水车在江畔 (15.5,30) 慢慢转）。原始社会底色下它的形态是大道古道：土路、驿站、渡口，不出现现代路名设施。南延出坝经铜壁关去陇川——铜壁关是两区之间的关口，陇川全域图的西线出口（铜壁关·盈江方向）与本图的南口在世界图上相对接，关口本体落在本图一侧 (−215, 448)（§5）。全域的村落基址全部挂在这条主轴及其三条支线（东线、西线、湖畔道）上，这就是总图的路网骨架。

## 6. 凯邦亚湖与铜壁关

- **凯邦亚湖**：任务口径原拟按 planned 落位，但现有场景 `yingjiang-scene.cjs` 已经把这座高山水库建出来了（丘体 + 丘顶湖面 + 坝体石墙，spec waters 末项 r15、碰撞圈 r24 在 (−168, 148)，方位正是坝西南高山，与真实方位一致）。按全域图的统一口径（built = 现有场景已有实物），本图如实标 **built**（纠偏记录见 §9）。湖畔道（§4）与湖南、湖西山麓两处基址（§7）都挂在它周边；户宋河自南入湖为 planned 水系。
- **铜壁关**：关口本体在现有场景里没有实物，标 planned，落在坝心大道南延的出口内侧 (−215, 448)；关外向西南即陇川坝（陇川全域图西线户撒道的西北出口与此相对）。两区图在关口处的口径一致：关是盈江侧的地标、陇川侧的出口方向，谁先建成由场景实现轮次排期，本契约不重复落位第二座关。

### 7.2 容量账（把数算清楚）

- **每村首期 8 块**：与瑞丽村落契约的定稿排布同口径（30×32、带土巷与公共保留的一整排村格局），新村开村即按这个数起步，不用临时凑地。
- **每村上限 32–48 块的估算依据**：单块地 30×32 = 960；连上土巷、土径、村心公共保留与地形损耗，平均每户实际占地约 1700–2200 游戏单位²；单个基址周边的可安家地带约 7–10 万单位² → 约 32–48 户。逐村按地形给值（坝田最开阔 48、河谷/山麓最窄 32，见上表），不是一刀切。上限是**总图估算**：每一轮实际扩村排布仍须按村落契约的判定（压路 ≥ 8、压水、保留区）逐块校验后才生效。
- **盈江一区合计**：11 处基址，首期 **88 户**，全图扩满 **424 户**（模块 `REGION_CAPACITY` 由基址表求和，文档与测试都用这个数，不另算一份）。
- **五区合计推算口径**：瑞丽已定稿 420 户、陇川 428 户（同日另交）、盈江 424 户；芒市、梁河两区尚未做全域图，按同标准每区约 400–480 户推算，**五区合计约 2000–2400 户**，基址加密可达约 3000 户量级。这是量级推算，不是承诺数：每区的实际数以各自全域图落位为准。
- **在线承载口径（与交接文档一致，不另立说法）**：几千人同时在线靠**多村落 + 邻近订阅 + 在线频道**承载——玩家分散在几十个村落与公共区里，客户端只绘制邻近范围的人；**地权与频道分离**：家园占地是持久目录数据（主人不在线，地和房子也在），频道只是临时在线分片，换频道不换地。**不承诺几千人同屏**，也不伪造在线人数。村满了由服务端按本表的预留基址开新村（新 `villageId`），**老村坐标与已分配地块永不重排**——先住下的人，家永远在原地。

## 9. 打折、纠偏与待确认（如实记录）

- **凯邦亚湖口径纠偏**：本区任务口径原拟把凯邦亚湖按 planned 落位，但现有场景已经把它建成实物（丘顶湖面、坝体、水面圆与碰撞圈俱在），总图按统一口径标 built（§6）。这不改变它的玩法状态：湖在高山丘顶，当前没有登湖路径，仍是望湖/远眺点；湖畔道与登湖动线属后续场景实现轮次。
- **榕树王方位纠偏**：2026-11-13 地方图设计稿把榕树王画在坝西南、铜壁关旁；现有场景 `yingjiang-scene.cjs` 把它建在坝西北 (−128, −88)（注释亦称「榕树王（西北）」）。总图以现有场景为准（built，锚点不挪），设计稿的西南落位不再采用；铜壁关本体单独按 planned 落在西南出口（§6），两者不再是设计稿里的相邻关系——将来场景实现轮次若要正位，另行评估，本轮只记录出入。
- **总图大 ≠ 现在就能玩那么大**：masterPlan 是规划范围，其内 planned 的地形、水系渲染、碰撞、植被都还不存在；当前唯一可玩范围仍是 playableNow 椭圆。1320×980 是「能做多大做多大」的总图尺度承诺（落位与目录先行），不是现状描述。
- **旧城只有水面**：两江交汇是现有场景的水面格局，旧城本体（聚落、驿站）没有实物，标 planned；渡口竹筏同样只有设计稿意象、无现有实物，标 planned，不与瑞丽渡口的 built 竹筏混淆。
- **村落上限是估算**：§7 的 32–48/村与五区 2000–3000 户是按占地口径的量级推算；逐村扩容要在后续排布轮次逐块过校验，校验不过就降上限，不硬塞。
