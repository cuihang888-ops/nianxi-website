# 梁河全域大地图布局（2026-11-15）

收件人：Codex。配套数据模块：`wechat/vendor/lianghe-region.cjs`（本文所有数值从该模块抄录，两边以模块为准；模块测试 `tests/lianghe-region.test.mjs`，并与现有场景锚点做交叉一致性断言）。
基线：`muse/shared-world-scenes` @ `8609905`（瑞丽全域图定稿之上）。用户要求（2026-11-15）：「顺便把其他城市的地图一起做了」——其余各区按瑞丽同一标准出全域图：能做多大做多大、标志性东西按真实大概位置摆、为几千人同时在线留足安家地（容量账见 §7）。
本契约只定全域布局与坐标口径，不表示规划区已建成、已可玩；现状与规划在数据里逐项用 `status: built | planned` 区分（见各表）。

## 1. 范围与两层口径

全域坐标用**坝内坐标**（与现有梁河场景 `lianghe-scene.cjs` 的 spec 同一套：右手系、Y 向上、北 −Z、东 +X，`yaw = atan2(dx, dz)`，游戏单位不宣传为现实测绘米）。梁河走通用坝引擎 `dam-world`，锚点抄自该 spec 与 decorate 落位；集市卖货点另以 `preview-discovery.cjs` 的 `MARKET_POS.lianghe` 为准。现有锚点一律不挪位，总图只向外扩：

## 2. 坐标与投影

- 本模块坐标即坝内坐标，不存在第二套村落坐标换算（瑞丽的村落坐标平移是瑞丽村落契约特有，本区无此层）。
- 全域小地图投影（模块 `worldToMap` / `mapToWorld`，互逆，测试覆盖）：中心取总图几何中心 (20, 0)，比例 **0.5 地图单位 / 游戏单位**（总图映为 540 × 430 地图单位）；朝向定义与瑞丽版相同——map.x 东为正、map.y 向下为正（南在下、北在上，指北向上）。地图定位只读，不触发传送（交接文档红线不变）。
- 交叉一致性已由测试断言：大厅 (−6,8)、水晶 (−11,19)、宣抚司署 (−20,−18)、勐底大金塔 (128,−64)、金塔温泉 (104,−34)、帮盖金葫芦 (−59,89)、回龙茶山 (−142,−30) 与现有场景本体逐字一致；集市与 `MARKET_POS.lianghe` 同点互验；两个现有基址与 spec `sites` 落位一致。

## 6. 安静的安家区：梁河的产品定位

- 五坝里梁河是**最安静、最宜居**的一区：没有大集市的喧闹，没有中枢的人流，节奏就是茶山、温泉、古镇老街与一条江。总图的基址密度因此有意不向芒市看齐——12 处基址沿江、沿河谷、沿茶山脚散布，村与村之间留足田野与山林，**安静本身就是这区的卖点**，扩容优先开新村而不是把老村塞满。
- 帮盖是葫芦丝的发源地（金葫芦 built 在村口）、回龙茶是梁河的名片、两处温泉（金塔温泉 built、底养温泉 planned）给「歇脚」留了天然的落点——这些都按真实方位落了位，玩法侧以后做茶山采摘、温泉歇脚、葫芦丝之夜时，地图数据已经就绪。

### 7.2 容量账（把数算清楚）

- **每村首期 8 块**：与村落契约的定稿排布同口径（30×32、带土巷与公共保留的一整排村格局），新村开村即按这个数起步。
- **每村上限 32–48 块的估算依据**：单块地 30×32 = 960；连上土巷、土径、村心公共保留与地形损耗，平均每户实际占地约 1700–2200 游戏单位²；单个基址周边的可安家地带约 7–10 万单位² → 约 32–48 户。梁河谷地多、开阔地少，逐村给 32–40（坝田/南田最开阔 40、江北/河谷/茶山脚等窄谷 32，见上表），不是一刀切。上限是**总图估算**：每一轮实际扩村排布仍须按村落契约的判定（压路 ≥ 8、压水、保留区）逐块校验后才生效。
- **梁河一区合计**：12 处基址，首期 **96 户**，全图扩满 **420 户**（模块 `REGION_CAPACITY` 由基址表求和，文档与测试都用这个数，不另算一份）。
- **五区合计进度**：已定稿全域图三区——瑞丽 420 户、芒市 460 户、梁河 420 户，合计 **1300 户**；陇川、盈江两区全域图另行施工中，五区总量待五张图齐后按各区实际落位重算（按当前三区口径推算仍在约 2000 户量级，加密基址可达约 3000 户量级；量级推算，非承诺数）。
- **在线承载口径（与交接文档一致，不另立说法）**：几千人同时在线靠**多村落 + 邻近订阅 + 在线频道**承载——玩家分散在几十个村落与公共区里，客户端只绘制邻近范围的人；**地权与频道分离**：家园占地是持久目录数据（主人不在线，地和房子也在），频道只是临时在线分片，换频道不换地。**不承诺几千人同屏**，也不伪造在线人数。村满了由服务端按本表的预留基址开新村（新 `villageId`），**老村坐标与已分配地块永不重排**。

## 9. 打折、纠偏与待确认（如实记录）

- **总图尺寸如实打折**：梁河 masterPlan 1080×860 小于瑞丽（1320×950）与芒市（1340×960）。原因是真实的：遮岛坝是五坝里最小的坝子，四周环山，可安家的平坝与谷地就这么多。总图已经把萝卜坝（坝北山间小坝）、龙江源谷地、勐养江河谷都计入规划范围，仍达不到 1200×900——本文不把山体硬算成可安家面积充数。容量靠基址密度补（12 处、420 户，与瑞丽同量级），靠的是沿江沿谷的带状安家带，不是靠摊大饼。
- **帮盖方位以现有场景为准**：2026-11-13 地方图设计稿把帮盖画在坝东南（勐养方向），现有场景把帮盖金葫芦建在宣抚司署西南 (−59,89)、紧邻基址 0001。总图按**现有场景**落位（built 不挪）；设计稿的东南方位只用于底养温泉与勐养道的 planned 落位参考。真实地理上帮盖在遮岛镇西南一带，与场景落位一致，设计稿画法是示意性的。
- **大盈江走向以现有场景为准**：设计稿把大盈江画成坝北的东西向水带，现有场景建成南北穿坝（入境在北、出坝在南）。真实大盈江在梁河段自北向南流，与场景一致；总图按场景折线（built 不挪），设计稿的北部水带只作萝卜坝河谷的方位参考。
- **九保古镇与集市同位**：真实九保在遮岛以北数公里，现有场景只在集市点 (26,66) 建了石板街口的古镇意象，与集市卖货点同点。总图如实并列两条地标（同坐标、同为 built），不另画一个假坐标；九保独立镇区如需展开，属后续场景实现轮次，届时在坝北古道旁另定落位并更新本表。
- **总图大 ≠ 现在就能玩那么大**：masterPlan 是规划范围，其内 planned 的地形、水系渲染、碰撞、植被都还不存在；当前唯一可玩范围仍是 playableNow 椭圆。
- **村落上限是估算**：§7 的 32–40/村是按占地口径的量级推算；逐村扩容要在后续排布轮次逐块过校验，校验不过就降上限，不硬塞。
