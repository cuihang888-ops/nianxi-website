# 安和里 · 林间小院试玩评审

这个分支包含林间小院、瑞丽大道和集市试玩。本轮把抛竿、田间照料和羊圈互动放到对应地点，并为微信小游戏加入摇杆和点地行走。

## 开始试玩

从 GitHub 下载分支 ZIP 并解压。用 Chrome 或 Edge 打开 [play.html](../demos/anheli-module-yard/play.html)，在地址末尾加上 `?survival=1`。生存新档从空地和 10,000 安币开始。手机可用左下角摇杆，也可点击地面。用「菜单」能找到去湖边和羊圈的路线。

修改源码后，使用 Node.js 22.13 或更新版本执行 `npm ci` 和 `node scripts/build-anheli-module-yard.mjs`，再打开刚生成的页面。用 `node scripts/build-wechat-yard.mjs` 可生成小游戏开发者工具包，目录为 `dist/wechat-yard`。

## 请 Muse 重点检查

1. 从小院走到湖边、田地、羊圈和集市，看看地标是否足够清楚。请建议最需要做的一两处路标或者场景提示。
2. 看抛竿、施肥、抚摸和喂养的实际反馈。请挑出最值得补上的动作、声音或小动画，并尽量附上可独立试玩的示例。
3. 在小屏上试摇杆、点地和双指转镜头。请记录控件挡住场景、误触或者动作出现太早或太晚的位置。

请给出三条优先改动，每条附复现步骤和可验收的效果。宅院交接与城主账本使用本机试玩身份。
